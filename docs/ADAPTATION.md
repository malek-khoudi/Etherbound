# Adaptation Ledger

Game abstractions that are NOT canon. Nothing in this file is a fact about Harth.
Every entry here exists because a game cannot simulate everything.

Last updated: 2026-09-08

---

## Standing rule

Authored uncertainty must stay distinguishable from rules the player can reliably predict.
If the player cannot predict it, the game must say so before they commit.

---

## Approved abstractions

| Abstraction | Why it exists | Canon status |
|---|---|---|
| Turn-based rounds | Tactical readability | Not canon. Harth has no turns. |
| Action points | Bounds commitment per unit per round | Not canon. |
| Grid or zone movement | Predictable positioning | Not canon. |
| Numeric reserve / throughput bars | Player must see commitment cost | Abstraction OF a canon constraint. The constraint is real, the number is not. |
| Injury categories | Vital repair vs recovery must be legible | Abstraction OF a canon distinction. |
| Authored material whitelist | Cannot simulate all physics | Not canon. Materials behave consistently within the whitelist only. |
| Structural connection graph | Kinetic anchors, Transmutative fronts, load paths | Simplified model of real canon physics. |
| Thermal reservoir model | Thermic needs a sink | Simplified model of real canon physics. |
| Tactical overlay UI | Shows anchors, load paths, sightlines | Optional UI. NOT visible in-world. See CANON.md visual rules. |

## Design constraints carried from the assessment

- Display useful **predictions** before commitment, and **plain-language reasons** for failure.
- A tactical encounter must support **rescue, containment, withdrawal and protecting evidence**, not only defeating enemies.
- A Kinetic holding a load **cannot** commit full output elsewhere. This must be mechanically enforced, not narratively implied.
- Progression adds control, technique, preparation and understanding. It never sells an unrelated affinity.

---

## Slice 1 target

30 to 60 minutes of **finished play**. This is a content target, not a development-time promise.

1. Short work assignment teaches the site's machinery, people and routes.
2. Developing failure creates a rescue problem with multiple viable approaches.
3. Post-incident evidence conflicts with somebody's account. Player chooses whom to trust and what to report, and sees a material consequence before the slice ends.

One map. Small cast. Small whitelist of interactions.
Proves: reserve/commitment, environmental causality, dialogue, save/load, aftermath.

Expand only after unfamiliar players understand the rules and enjoy making decisions.
